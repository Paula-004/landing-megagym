# MegaGym

Landing responsive para un gimnasio. Presenta las áreas de entrenamiento, horarios, ubicación y eventos, e incluye un portal de rutinas y un panel de gestión para entrenadores.

## Tecnologías

React, Vite y CSS.

## Ejecutar en local

Requiere Node.js 22.12 o posterior.

```sh
npm ci
npm run dev
```

Para generar la compilación de producción, ejecutá `npm run build`.

## Estado del proyecto

El portal permite consultar rutinas semanales y mensuales con los números de socio de muestra `1001` y `1002`. El panel incluye cuentas de demostración. Los cambios se guardan en el navegador mediante `localStorage` y la autenticación se simula en el cliente.
